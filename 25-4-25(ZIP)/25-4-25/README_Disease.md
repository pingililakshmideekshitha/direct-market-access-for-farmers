# Crop Disease Detector

A web application that uses AI to detect crop diseases from images. Built with HTML, CSS, JavaScript, and Supabase.

## Features

- Drag and drop image upload
- Image preview
- AI-powered disease detection
- Detailed analysis results
- Responsive design
- Data storage with Supabase

## Setup

1. Clone the repository
2. Create a Supabase project and get your credentials
3. Update the Supabase URL and key in `script.js`
4. Open `index.html` in your browser

## Project Structure

- `index.html` - Main HTML file
- `styles.css` - CSS styling
- `script.js` - JavaScript functionality
- `README.md` - Project documentation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Supabase (Database)
- Font Awesome (Icons)
